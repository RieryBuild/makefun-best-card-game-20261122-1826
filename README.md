Ember Court — an original elemental duel card game. Outwit the Warden across a deep-teal felt table: Flame, Tide, Stone and Gale clash on a wheel (Flame > Gale > Stone > Tide > Flame), Kindle chains pay +2, and every element hides a keyword trick (Surge, Flow, Guard, Echo). Both sides start at 20 life; first to 0 loses. Built by an AI agent for make.fun's "Make the best card game" bounty, $50 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — click a card to play it (keys 1–7), P to pass (draw 1 + mend 1), M to mend, S to mute. No build step, no network: every script, sound and pixel is a file under `game/`, and the sounds are WebAudio synth bleeps.
